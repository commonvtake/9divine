# Third-party software

9divine bundles the following libraries in `third_party/`. Each folder contains the library's own license file.

| Library | Version | License | Used for |
|---|---|---|---|
| [GLFW](https://www.glfw.org) | 3.4 | zlib | Windows, input, gamepads |
| [glad](https://github.com/Dav1dde/glad) (generated loader shipped with GLFW) | 2 | Public domain (CC0) + Khronos (Apache 2.0) | OpenGL function loading |
| [GLM](https://github.com/g-truc/glm) | 1.0.1 | MIT | Math |
| [Dear ImGui](https://github.com/ocornut/imgui) (docking) | 1.91.8 | MIT | Editor UI |
| [ImGuizmo](https://github.com/CedricGuillemet/ImGuizmo) | master | MIT | Transform gizmos |
| [stb](https://github.com/nothings/stb) (image, image_write, truetype, rect_pack) | master | MIT / public domain | Images, fonts |
| [cgltf](https://github.com/jkuhlmann/cgltf) | 1.14 | MIT | glTF import |
| [tinyobjloader](https://github.com/tinyobjloader/tinyobjloader) | 2.0.0rc13 | MIT | OBJ import |
| [ufbx](https://github.com/ufbx/ufbx) | 0.18.2 | MIT / public domain | FBX import |
| [miniaudio](https://github.com/mackron/miniaudio) | 0.11.21 | MIT-0 / public domain | Audio |
| [nlohmann/json](https://github.com/nlohmann/json) | 3.11.3 | MIT | Serialization |

Assets: Roboto and Cousine fonts (Apache 2.0, from Dear ImGui), Fox model from the Khronos glTF Sample Assets (CC0 / CC BY 4.0, see `projects/Demo/Models/Fox/LICENSE.md`).
